# World Layoffs Exploratory Data Analysis (EDA)

This project explores the cleaned global layoffs dataset using advanced SQL queries in MySQL Workbench to uncover meaningful trends, patterns, and insights.

## Key Questions Explored
- Which countries and industries suffered the highest total layoffs?
- What is the overall timeline and date range of the dataset?
- What were the single largest layoff events in a single day?
- How did layoffs trend year-over-year and month-over-month (including running totals)?
- Which companies ranked in the top 5 for layoffs across individual years?

## Tech Stack
- **Database:** MySQL
- **Tool:** MySQL Workbench
- **Language:** SQL

## How to Run
1. Clone or download this repository.
2. Open MySQL Workbench and run the `layoffs_eda.sql` queries against your cleaned database table.
